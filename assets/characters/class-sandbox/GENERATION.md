# Class sandbox artwork

All assets generated with the built-in image generation tool and copied into this directory without modifying RGBA pixels. JSON contains geometry-only alpha contour analysis, measured pose roots and grip positions; it does not alter the source artwork. Strider's extended whip uses a concave outline to exclude neighboring figures. Item atlas regions are explicitly measured because generated rows are not evenly spaced.

Source directory: `/home/makalu/.codex/generated_images/01a0d330-f594-7e10-b619-876f266ede9f/`.

These are sandbox animation drafts. Female Warden shares a three-phase attack gesture across weapons; weapon sprites attach at measured hands. Wildborn has four bounding run poses, distinct Briar/Rootbind/Prowler outfits, and three additional Feral action poses. Hexbinder has glide poses and four elemental casting gestures. Jump/burrow transitions partly reuse these poses. Further full-motion art cleanup remains a review task, not a claim of final animation quality.
