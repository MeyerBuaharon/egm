# Rebuilt run — September 29, 2026

Strider and Wildborn now use a continuous two-leg rig (`scripts/roster_run.gd`), rather than selecting poses from the rejected run-v2 cycle. The original torso, face, scarf/mantle and held weapons remain painted artwork. New thigh, shin and foot textures provide complete hidden surfaces and overlapping joints. The newly generated torso components are deliberately unused to preserve character identity.

Each leg has its own contact-to-push-off track and raised recovery track, half a cycle apart. Two-bone inverse kinematics retains constant segment lengths. Foot rotation is independent of the shin. Foreground/background drawing order stays consistent; the far leg is shaded. Foot displacement matches the 110-unit Strider / 100-unit Wildborn travel per cycle, preventing stance-foot skating at steady velocity. Facing mirrors the complete assembled character. No per-frame UV stretching is used. Upper-body motion is a subtle rock; arms remain in the painted armed-running pose, not independently counter-swung.

The isolated render scripts inspect both directions, gameplay size and close-up. `tests/run_rig_behavior.gd` checks foot alternation, wrap continuity, support height, ground travel, limb lengths and idle/jump/burrow state selection. Frame coverage alone is not evidence of anatomical correctness.
